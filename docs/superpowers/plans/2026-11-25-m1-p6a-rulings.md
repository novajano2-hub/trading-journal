# Plan 6A: rulings made during the build

Every decision taken on the owner's behalf while building Plan 6A (the progress tracker, the day page, the Day and Week views, getting started), in the order made: first the spec's Keel's calls, then the main session's ledger, then the two merged session branches (the Trades views, module D; getting started, module E). Each says what was decided, why, and what it costs if wrong. Rework any you disagree with.

Each item carries a tag:

- **[TZ unknown]** a genuine TradeZella unknown: the record, the connector and the help do not settle it, so Keel chose.
- **[Record answers]** the record settles it; listed because the spec first held it as a question.
- **[Keel design]** a design, mapping or wording call that is Keel's own (TradeZella has no counterpart, or the look is Keel's).
- **[Infrastructure]** a build, storage, test or process call.
- **[Owner]** decided by the owner.

The two questions still open for the owner are at the end.
